# 아이템(유물) 시스템 — 전술카드에 흡수됨

> 최종 업데이트: 2026-07-29
> **상태: 폐기 → 통합.** 이 문서가 정의하던 "플레이어가 소유하는 유물 슬롯 계층"은
> **전술카드와 같은 자리**였으므로 2026-07-29 자로 **전술카드로 통합**되었다.
> 전술카드는 **상점에서 코스트로 구매 · 전술 슬롯(잠정 5) 안에서 상시 발동**한다 — 병력과 **하나의 코스트 예산**을 두고 경쟁한다(무통화, GAME_DESIGN §4).
> 현행 설계 → [GAME_DESIGN.md §7 전술카드](GAME_DESIGN.md)

---

## 1. 왜 통합했나

기존 유물 시스템과 전술카드의 정의를 나란히 놓으면 **같은 것**이다.

| 축 | 기존 유물 | 전술카드 |
|---|---|---|
| 소유 주체 | 플레이어 (유닛 아님) | 플레이어 (덱과 분리) |
| 지속성 | 한 번 얻으면 모든 라운드에 영향 | 상시 발동 — 한 번 사면 이후 라운드에도 켜져 있음 |
| 개수 제한 | 고정 슬롯, 가득 차면 교체 | 전술 슬롯(잠정 5), 가득 차면 교체 — 코스트로 병력과 경쟁 |
| 발동 | 전투 시작 시 자동 | 자동, 플레이어 조작 없음 |
| 획득 | 상점/보상 | 상점에서 코스트로 구매 |

두 계층을 동시에 두면 플레이어는 **"상시 효과 주머니"를 두 개** 관리하게 되고, 어느 쪽에 무엇이 들어가는지가 자의적이 된다.
전술카드가 이 게임의 정체성(전투 이벤트 엔진)을 짊어지기로 한 이상, 유물은 전술카드의 하위집합일 뿐이다.

## 2. 전술카드로 이관된 것

| 기존 유물 개념 | 전술카드에서의 처리 |
|---|---|
| 플레이어 인벤토리 (고정 슬롯) | 전술카드 보유 — **전술 슬롯(잠정 5칸)**으로 제한 |
| 슬롯 가득 시 교체 모달 | 예산 압박으로 대체 — 유닛과 전술 중 무엇에 코스트를 쓸지가 커밋 압박 |
| 효과 전문 노출 (숨겨진 효과 없음) | 동일 — 완전 정보 원칙 |
| 전투 시작 시 1회 합산 | 확장됨 — 전술카드는 **전투 중 이벤트에도 반응**한다 |
| `scope` 필드 (ALL_ALLIES / CONDITIONAL / GLOBAL) | 전술카드 조건 문법으로 흡수. CONDITIONAL의 조건 키는 **종족·직업 태그**가 담당 → [SYNERGY_DESIGN.md](SYNERGY_DESIGN.md) |
| GLOBAL(메타 자원 수정자) | **코스트·경제 조작 전술카드**로 승격 — 코스트가 유일 자원이므로(천장 부스트·판매 잔재, GAME_DESIGN §4·§6) 최상위 빌드어라운드 |

**살릴 만한 설계 자산:** `scope` 3분류는 전술카드 효과 범위를 정리하는 어휘로 여전히 쓸모 있다.
전술카드 카탈로그를 짤 때 "전군 / 조건부(태그) / 메타(코스트·경제)" 축으로 나누면 커버리지 점검이 쉬워진다.

## 4. 남은 과제 (전술카드 설계로 이관)

- 전술카드 보유 상한 — 잠정 5칸 슬롯 (§7·§4, 슬롯 수 변경 가능)
- 동일 전술카드 중복 보유 허용 여부
- 구매/교체 시 환불 유무
- 전술카드 등급·세트 효과

> **해소된 항목:** "어떤 자원을 쓰는가"는 확정됐다 — 전술카드는 **상점에서 코스트로 구매**하고 **전술 슬롯(잠정 5)**으로 제한되며, **하나의 코스트 예산을 병력과 나눠 쓴다**(무통화, GAME_DESIGN §4·§7).
> 위 미결 항목은 [GAME_DESIGN.md §12 미결 항목](GAME_DESIGN.md)에서 추적한다. 이 문서는 더 이상 갱신하지 않는다.
