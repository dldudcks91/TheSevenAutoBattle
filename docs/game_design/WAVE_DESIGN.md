# 웨이브 디자인

> 최종 업데이트: 2026-05-07
> 한 런 = 20웨이브 / 4챕터. 각 웨이브가 어떤 학습 포인트를 시험하는지의 의도를 담는다.
> 적 라인업·카운트 등 데이터는 [src/data/rounds.csv](../../src/data/rounds.csv) 에서 관리.
> 적 유닛 카탈로그 → [UNIT_DESIGN.md §3](UNIT_DESIGN.md)

---

## 1. 디자인 원칙

1. **웨이브 1개 = 메카닉 1개 학습** — 새 적은 한 웨이브에 1종만 도입하고, 다음 웨이브에서 응용·혼합한다.
2. **챕터 첫 웨이브는 완충** — 적 수를 살짝 줄이고 신규 메카닉을 단독으로 공개해 학습 시간을 준다.
3. **챕터 마지막 웨이브는 미니보스** — 챕터 내 모든 메카닉을 섞고, 직전 챕터 적도 일부 잔향으로 남긴다.
4. **보스 wave는 "보스 단일 위협 + 보스를 강하게 만드는 호위"** — 호위 자체보다 호위 효과로 보스의 위협이 증폭되는 구도.
5. **카운트 곡선은 단조 증가, 보스 wave만 살짝 줄이고 보스 강함으로 보충.**
6. **시너지 학습 곡선** — 챕터별 적 종족이 단일이라, 플레이어는 "이 종족에 강한 아군 시너지가 무엇인가"를 학습할 시간을 갖는다 → [SYNERGY_DESIGN.md](SYNERGY_DESIGN.md).

## 2. 챕터 구조

| 챕터 | 웨이브 | 적 종족 | 핵심 학습 |
|---|---|---|---|
| 1 | W1~5 | **Orcs** | 카드·시너지 시스템 흐름 → 방어력 개념 → 숫자 압박 → 미니보스 |
| 2 | W6~10 | **Undead** | 원거리 위협 → 부활 → 디버프 → 기동(후방 침투) → 미니보스 |
| 3 | W11~15 | **Demons** + 혼합 | 매혹·화염 광역 → 단일 정예 → 종합 압박 → 미니보스 |
| 4 | W16~20 | **혼합 엔드게임** | 전 챕터 메카닉 종합 + 챕터 4 신규 핀치 → **최종보스** |

## 3. 웨이브별 의도

### Chapter 1 — Orcs (기초 학습, W1~5)

| 웨이브 | 학습 포인트 | 압박 강도 |
|---|---|---|
| W1 | 카드 추첨 → 셀 배치 → 시너지 패널 확인 → 전투 시작 흐름 익히기. 실패하기 어려운 입문 라운드. | 매우 약함 |
| W2 | **방어력의 의미** — 오크 정예의 두꺼운 맷집을 평타로 깨는 게 답답함을 체감. 방어 무시 마법 또는 방어 감소의 필요성. | 약함 |
| W3 | **숫자 압박** — 고블린/오크 잡몹 다수 + 광폭형 등장. 처치 타이밍 학습. 누적 골드로 그리드를 확장했는지 시험. | 보통 |
| W4 | **지휘관 + 기마** — OrcWarChief의 강화 효과 + WargRider/WolfRider의 후방 침투. 우선 처치·도발 학습. | 강함 |
| W5 | **챕터1 미니보스** — OrcWarChief 다수 + 정예 오크 호위. 챕터1 메카닉 종합 시험. | 미니보스 |

### Chapter 2 — Undead (메카닉 도입, W6~10)

| 웨이브 | 학습 포인트 | 압박 강도 |
|---|---|---|
| W6 | **원거리 위협 첫 등장** — Skeleton Archer로 후방도 안전하지 않음을 학습. 전선 차단·원거리 우선 처치. | 보통 |
| W7 | **물리 저항(Ghost) + 부활** — Ghost는 마법으로만 잡힘. Necromancer가 잡몹을 다시 일으킨다. 마법 딜러·우선 처치 학습. | 보통 |
| W8 | **디버프** — Lich의 광역 디버프와 DeathKnight의 저주 공격. 정화·빠른 정리 압박. | 강함 |
| W9 | **기동 위협** — Reaper가 후방 빈사 아군을 노린다. 회복·격리 운용 점검. | 강함 |
| W10 | **챕터2 미니보스** — DreadKnight + Lich + Reaper 호위. 디버프와 기동이 동시에 가해지는 종합 시험. | 미니보스 |

### Chapter 3 — Demons + 혼합 (극단 압박, W11~15)

| 웨이브 | 학습 포인트 | 압박 강도 |
|---|---|---|
| W11 | **매혹** — Succubus의 매혹/공격 분산. 정화·빠른 처치 학습. | 강함 |
| W12 | **화염 광역** — DemonFireKeeper의 광역 화상 + DemonFireThrower의 원거리 화염. 광역 회피·전선 차단. | 강함 |
| W13 | **도발·피흡 핀치** — DemonTormentor가 전선을 잡아두고 적 정예가 후방을 타격. 우회·다발 화력. | 매우 강함 |
| W14 | **혼합 핀치** — 챕터1·2 적 일부 합류 + 데몬 정예. 시너지 풀빌드 가치 점검. | 매우 강함 |
| W15 | **챕터3 미니보스** — HighDemon 또는 Demoness 메인 + 데몬 호위. 단일 위협 + 광역 동시 처리. | 미니보스 |

### Chapter 4 — 엔드게임 혼합 (W16~20)

| 웨이브 | 학습 포인트 | 압박 강도 |
|---|---|---|
| W16 | **종합 압박** — 3챕터 메카닉이 모두 동시에. 시너지 풀빌드 없이는 클리어 어려움. | 매우 강함 |
| W17 | **편성 다양성 시험** — 한 종류 도배가 통하지 않는 균형 잡힌 적 구성. 시너지 두 축 모두 활용 강제. | 매우 강함 |
| W18 | **혼돈 — 카오스 웨이브** — 다수 종족 적이 한꺼번에 등장. 직업 시너지 의존이 효과적인 라운드. | 매우 강함 |
| W19 | **최종보스 직전 점검** — 보스를 잡으려면 어떤 카운터가 있어야 하는지를 마지막으로 시험. | 매우 강함 |
| W20 | **최종보스** — BigMonsters 풀의 거대 단일 (예: BlackDragon, DemonLord 등) + 호위. 호위 효과로 보스 위협 증폭. 클리어 시 RUN CLEAR. | 보스 |

## 4. 적 카운트 곡선 (방향성)

- W1~5: 소수에서 시작해 챕터 끝(W5 미니보스)에서 정점
- W6~10: 챕터2 시작 시 한 단 늘리고, W10 미니보스에서 정점
- W11~15: 압박 점진 상승, W15 미니보스
- W16~19: 엔드게임 — 가장 많은 수 + 정예 비중 ↑
- W20: 보스 wave는 호위 포함 다소 줄임 — 수보다 보스 강함이 핵심

> 정확한 적 수는 [src/data/rounds.csv](../../src/data/rounds.csv) 참조. 본 문서는 의도만 담는다.
