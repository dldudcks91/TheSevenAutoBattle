## 1. 게임 개요

- **장르:** 덱빌딩 로그라이크 + 오토배틀 + **조커 엔진** (PvE)
- **플랫폼:** Steam (PC)
- **핵심 한 줄:** "덱은 네가 짠다. 매 전투, 코스트 안에서 최선의 군대를 뽑아내라."
- **수익모델:** 스팀 단일 구매 (인앱결제 없음)

### 정체성 전환 — 왜 누적에서 덱빌딩으로

- **기존(누적):** 영구 군대를 그리드에 쌓고 유지. 문제 — 후반엔 편성이 고정되어 **전투 준비 결정이 사라지고 관전만 남는다.**
- **전환(덱빌딩):** 영구 자산을 **덱(카드 컬렉션) + 조커** 로 옮긴다. 매 전투 손패를 새로 뽑고 코스트 예산 안에서 편성하므로 **준비 결정이 매 판 살아있다.**

### 우리만의 자리 (경쟁 지형)

- 오토배틀 + **조커 엔진** + **드로우 덱**, 이 셋을 한 그릇에 담은 게임은 아직 없다. (발라트로=점수, TFT=임계 시너지, Super Auto Pets=시너지가 유닛 자체에, Backpack Battles=공간배치 — 각자 하나씩 빠짐)
- 우리 승부수: **전투 자체가 조커 콤보로 폭주하는 오토배틀.** 점수 곱연산이 아니라 **전투 이벤트 엔진**으로.

## 2. 핵심 루프

각 라운드는 **전투 준비 → 전투 → 종료 → 덱/조커 편성**으로 돈다.

> **자산 모델:** 영구 자산은 **덱(병사·강화 등 카드), 조커(상시 슬롯), 골드** 다.
> **전장(배치판)은 영구가 아니다** — 매 전투 손패에서 임시로 꾸리고, 끝나면 초기화된다.

```
[런 시작] 약하고 단순한 초기 덱 + 빈 조커 슬롯

[매 라운드]
  1. 전투 준비
     - 적 편성 공개 (완전 정보)
     - 덱에서 핸드 드로우
     - 배치 코스트 예산 안에서 카드를 자유 배치 (핸드 장수 제한 없음):
         · 병사 카드    → 전장에 투입 (코스트 소모)
         · 시한부 강화  → 투입한 병사에 부착, 이번 전투만 (코스트 소모)
     - 남는 예산은 버려진다
     - 핸드가 마음에 안 들면 "버리기"(선택 버리기 → 덱에서 재드로우), 횟수 제한
     - 조커는 상시 발동 — 준비/전투 내내 켜져 있음
     - "전투 시작" 으로 배치 확정

  2. 전투 (오토배틀)
     - 개입 없음. 배치 + 조커의 결과만으로 판정.

  3. 전투 종료
     - 낸 카드는 모두 덱으로 회수 (전장 초기화)

  4. 덱/조커 편성 (전투 외)
     - 새 카드 획득 · 기존 카드 강화(영구) · 카드 제거(덱 압축)
     - 조커 획득/교체 (슬롯 제한 → 무엇을 넣고 뺄지)

[런 종료] 패배 or 보스 클리어 → 모든 자산 초기화
```

**핵심 긴장감**
- **매 전투 배분:** 예산 안에서 "정예 하나 + 강화 몰빵(코스트 큼) vs 잡병 물량(코스트 효율)" — 배낭(knapsack) 퍼즐.
- **덱 구축(장기):** 무엇을 넣고 강화하고 버릴지. 코스트 커브를 어떻게 짤지.
- **조커 커밋(장기):** 슬롯이 제한적 → 어떤 엔진 콤보에 올인할지.
- **자원 절약:** 골드는 카드·조커 획득·강화에만 쓰인다.

## 3. 덱 & 카드 시스템

### 기본 규칙
- **덱이 영구 자산이다.** 성장 = 카드 추가·강화·제거로 덱을 진화.
- **전투마다 핸드를 새로 드로우**하고, 낸 카드는 전투 후 **덱으로 회수**된다.
- **전장은 임시** — 종료 시 사라진다.
- **모든 카드는 코스트를 가진다** — 파워가 클수록 코스트가 크다. (§5)

### 두 종류의 "강화"를 구분한다
| 구분 | 무엇 | 지속성 |
|---|---|---|
| **시한부 강화 카드** | 핸드에서 병사에 부착하는 카드(코스트 소모). 몰빵/물량 결정의 축 | **그 전투에만** 유효, 전투 후 회수 |
| **덱 카드 강화 (전투 외)** | 덱의 특정 카드 자체를 상향 | **영구** |

> 강화가 특정 유닛에 **영원히 누적**되지 않는다. 전장에서의 강함은 매 전투 리셋되고,
> 영구 성장은 **덱·조커 계층**에서만 일어난다. (누적 모델의 개별 유닛 폭주 문제 차단)

### 카드 종류
**구현 목표 (프로토 검증 대상):** 병사 카드 / 시한부 강화 카드
**확장 후보 (검증 후 단계적):** 전술 주문(1회성) / 군단 오라(전군 지속) / 챔피언(성장형) / 조건 발동(트랩, §4) / 지형·포메이션
> 근거·전수조사 → [DESIGN_NOTES.md §4](../../prototypes/deck_draft_battle/DESIGN_NOTES.md). 카드 타입보다 **강화 카드 다양화(키워드형)** 가 값싼 깊이.

### 덱 관리의 깊이
- 덱이 커지면 원하는 카드가 덜 온다 → **카드 제거**가 전략(덱 압축).
- 코스트 커브 관리 — 싼 필러 없이 비싼 카드만 있으면 예산을 못 채운다.
- **싼 유닛도 죽지 않는다** — "예산 효율 좋은 필러" 역할. (흔한 오토배틀의 저코스트 유닛 도태 문제를 구조가 막음)

## 4. 전투

- **전투 전 1회 배치** — 준비 단계에서 확정하면 오토배틀이 개입 없이 한 번에 해결된다.
- 실시간 증원·수동 발동 등 **전투 중 조작은 없다** (오토배틀 정체성 유지).

### 전투 중 개입 없이 "중간에 터지는 드라마" — 조건 발동
- 카드/조커를 **내는 시점**과 효과가 **터지는 시점**을 분리.
- **조건 발동**은 배치 때 조건을 예약하고, 전투 중 조건 충족 시 **시스템이 자동 발동**. 플레이어 조작 없음.
- **수동 타이밍 발동은 도입하지 않는다** — 그건 액티브 카드배틀러로의 장르 이탈.

## 5. 편성 자원 — 배치 코스트 예산제

- 매 전투 준비 시, **배치 코스트 예산** 한도 안에서 카드를 낸다. **모든 카드에 코스트**가 있다.
- **핸드 장수 제한 없음** — 배치의 유일한 제한은 코스트 예산.
- **남는 예산은 버려진다** (매 전투 풀배치 유도).
- **핸드 개선은 "버리기"(횟수 제한)** — 상점 리롤이 아니라 **내 덱을 파는** 방식. 좋은 카드는 남기고 쓸모없는 것만 골라 버려 재드로우. 버린 카드는 버림 더미로 갔다가 덱 소진 시 셔플.

### 왜 "코스트 예산"인가 (points-buy, not turn-tempo)
- **턴 템포 코스트(하스식 매 턴 마나 커브)가 아니다.** 우리는 턴이 없다.
- **워게임식 points-buy** — 단일 배치에 맞고, 다음 장점이 있다:
  - **유닛 파워 티어를 살린다** (정예=비쌈=적게, 잡병=쌈=많이). 총횟수제는 이 티어를 버린다.
  - **완전 정보 배낭 퍼즐** — 공개된 적에 맞춰 예산을 딱 맞게 카운터.
  - **예산 자체가 성장 축** — 런 진행하며 배치 한도 상승 = 강해지는 실감.

### 배치 예산 = 이 게임의 프리미엄 자원 ("에너지" 등가물)
- StS에서 최강 보스 유물이 죄다 "에너지 +1"이었듯, 우리는 **배치 예산이 그 프리미엄 자원**이다.
- 따라서 **"배치 예산 확장 / 특정 종족·유닛 코스트 할인 / 첫 유닛 무료"** 같은 **코스트 조작 조커가 프리미엄 빌드어라운드 조각**이 된다. → 조커 계층과 코스트 예산이 백본으로 맞물린다.

## 6. 조커(유물) 엔진 계층 — TFT 임계 시너지 대체

> **결정:** 기존 [SYNERGY_DESIGN.md](SYNERGY_DESIGN.md)의 TFT식 임계 시너지는 **폐기**한다.
> 뽑기 변주가 있는 덱빌딩에선 "보드에 특정 종족 N종"을 안정적으로 못 맞추기 때문.
> 대신 **소유한 상시 조커**가 시너지·빌드 정체성을 짊어진다.

### 성격
- **덱과 분리된 상시 슬롯 계층.** 뽑기에 안 섞이고 항상 켜짐. **슬롯 제한제** → 무엇을 넣고 뺄지 선택 압박.
- 조커는 **전투 이벤트를 주고받는 엔진 조각**이다. 발라트로의 점수 곱연산이 아니라(우린 점수로 안 깸), **전투 상태·자원의 생산/소비 체인**으로 폭발한다.

### 상호작용 매개 (조커가 주고받는 통화)
처치 · 사망 · 상태이상 스택 · 소환 · 강화 이동 · 골드. → 한 조커가 생산한 것을 다른 조커가 소비하면 엔진이 된다.

### 설계 원칙 (StS 유물 분석에서)
- **엔진 + 페이오프** — 반복하는 조각 + 반복을 가치로 바꾸는 조각.
- **강효과엔 대가** — 고임팩트 조커는 전투 페널티를 동반(StS 보스 유물식). 명백한 정답이 아니라 고민되는 선택.
- **빌드어라운드로 런 정체성** — 종족·직업 태그를 조커 조건의 훅으로 재활용("Viking 처치 시…"). 얻으면 런 방향이 결정.
- **정액 스탯 필러는 최소화** — 우리는 카드 덱이 단순하므로 콤보 깊이를 **조커가 StS 유물보다 더 많이** 짊어져야 한다. (이게 "SAP 아류"를 벗어나는 지점)

### 획득·게이팅
- 사용 비용이 없으니 밸런스는 **획득으로만** 잡는다: 희귀도 + **보스 3택1(하나는 단점형)** + 골드 상점. → "얼마나 아끼냐" 골드 정체성과 결합.
- **슬롯 확장 자체가 성장 축.**

## 7. 완전 정보와 정체성

- **적 편성은 준비 단계에 완전 공개** — 카운터 픽 가시성 유지.
- **카드·조커 효과는 전부 노출** — 숨겨진 효과 없음.
- 덱빌딩이 들여오는 유일한 변수는 **드로우 순서**. 이는 로그라이크 운 요소로 취급하며, **덱을 좁혀 예측 가능하게 만드는 것**이 실력의 일부.
- **코스트 예산 배낭 퍼즐**이 "정보 다 줄게, 딱 맞게 짜봐"를 실현.
- 정체성 요약: **"무엇을 마주할지는 다 안다. 덱·조커를 어떻게 짜고, 예산 안에서 어떻게 대응하느냐가 실력이다."**

## 8. 기존 누적 모델과의 차이 (전환 요지)

| 축 | 기존 (누적) | 전환 (덱빌딩) |
|---|---|---|
| 영구 자산 | 그리드 군대 | **덱 + 조커** |
| 핸드 출처 | 전체 유닛 풀 랜덤 추첨 | **내 덱에서 드로우** |
| 전장 | 영구 (유지·부활) | **임시** (매 전투 초기화) |
| 강화 | 특정 유닛에 영구 누적 | **시한부**(전투) + **덱 카드 강화**(영구) |
| 편성 자원 | 골드 고용 | **배치 코스트 예산** (핸드 무제한, 버리기 횟수 제한) |
| 시너지 | 그리드 배치 임계 | **조커 엔진** (슬롯 제한, 전투 이벤트 체인) |
| 매 전투 결정 | 후반엔 배치 미세조정 | **매 판 예산 배분** |
