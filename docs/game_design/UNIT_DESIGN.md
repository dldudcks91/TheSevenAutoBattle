## 1. 디자인 원칙

1. **Player fantasy first** — 정체성을 먼저 정하고, 그 정체성을 행동으로 옮기는 스킬을 설계한다. 메커닉에서 정체성을 역산하지 않는다.
2. **태그 두 축 (직업·종족)** — 모든 아군 유닛은 직업 1 + 종족 1을 가진다 → [SYNERGY_DESIGN.md §4](SYNERGY_DESIGN.md). 직업은 7종이며, 전사가 옛 근접 3직업을 흡수했으므로 한 종족이 같은 직업(특히 전사)을 여럿 가질 수 있다. 태그 자체에는 효과가 없고 **전술카드 조건의 훅**으로만 쓰인다.
3. **고정 1스킬** — 유닛마다 고유 스킬을 정확히 하나 가진다. 카드로 추가 부여하지 않는다.
4. **상점에서 사서 필드에서 키운다** — 유닛은 상점에 등장하는 카드로, 파워에 비례하는 코스트를 가진다. 산 유닛은 지속 필드에 남아 라운드를 거치며 +5까지 육성된다 → [GAME_DESIGN.md §4·§8](GAME_DESIGN.md). 싼 유닛은 도태되지 않고 "코스트 효율 좋은 필러" 역할을 맡는다.
5. **에셋 기반** — 유닛 스프라이트·애니메이션은 minifolks 팩(아군 5종족) 및 minifolks 팩(적 3종족)을 사용한다.

## 2. 아군 — 5종족 / 35유닛

각 유닛은 종족 1 + 직업 1을 갖는다. 직업 카탈로그는 [SYNERGY_DESIGN.md §2](SYNERGY_DESIGN.md), 종족별 톤은 [SYNERGY_DESIGN.md §3](SYNERGY_DESIGN.md) 참조.

### 2.1 Humans — 정통 왕국군 (8유닛)

다재다능. 전열부터 후열·지휘까지 고루 갖춘 표준 진영. 근접 전사층이 두껍다.

| 유닛 | 직업 | Player fantasy |
|---|---|---|
| ShieldMan | 전사 | 방패로 전선을 지키는 정통 왕국 보병. |
| SwordMan | 전사 | 검과 깡으로 밀어붙이는 표준 보병. |
| SpearMan | 전사 | 길게 찌르는 창병. 기마 카운터. |
| CavalierMan | 기사 | 갑주 두른 기사 기마. 라인 돌파의 상징. |
| ArcherMan | 궁수 | 후방의 든든한 직업 궁수. |
| Mage | 메이지 | 정통 학파 마법사. 안정적 마법 딜. |
| ArchMage | 프리스트 | 신성과 학술의 경계에 있는 대마법사 — 아군 보호와 회복을 마법으로 수행한다. |
| KingMan | 영웅 | 왕의 명령 한 마디로 부대 전체가 움직인다. |

### 2.2 Vikings — 북방 광폭 전사단 (6유닛)

근접·기마·궁술의 전사 종족. 마법·치유 없음.

| 유닛 | 직업 | Player fantasy |
|---|---|---|
| VikingSwordman | 전사 | 양손검의 묵직한 전선병. |
| VikingBerserker | 전사 | 광폭화로 자기 피해를 무시하고 휘두르는 광전사. |
| VikingSpearman | 전사 | 북방 창병. 방패벽과 함께 서는 전열. |
| VikingHorseman | 기사 | 북방의 빠른 기마. 측면 돌파. |
| VikingArcher | 궁수 | 차가운 활시위로 멀리서 끊는 사수. |
| VikingJarl | 영웅 | 부족장. 함성으로 동족 전사를 폭주시킨다. |

종족별 동물 특성이 직업으로 직결되는 컨셉. 근접 전사 3종에 궁수·암살자·마법·지휘까지 두루 걸친 다양성 종족 (기사만 빠져 있다).

| WolfPathfinder | 궁수 | 늑대의 후각으로 적을 추적해 활로 끊는 정찰사수. |
| CatRobber | 암살자 | 고양이의 그림자 도둑. 후방 침투 전문. |
| RabbitWizard | 메이지 | 토끼의 조심성과 빠른 영창. 정통 마법사. |
| DeerDruid | 프리스트 | 자연의 사슴 사제. 식물 마법으로 치유. |
| LionKnight | 영웅 | 사자의 기백. 부대를 호령하는 야생의 군주. |

| FirePriestess | 프리스트 | 신성한 화염으로 아군의 상처를 태워 봉합한다. |

## 4. 배치 규칙

- 배치판은 **3×3 = 9칸이며 한 칸에 한 유닛**만 선다. 판은 **라운드 간 보존**되고, 전투에서 죽은 유닛도 다음 라운드에 부활한다 → [GAME_DESIGN.md §5](GAME_DESIGN.md).
- 같은 종류를 여러 칸에 두는 것은 자유다. 유리해지는 건 화력·맷집뿐이며 별도 보너스는 없다.
- 배치는 **필드 9칸 + 코스트 천장** 제약을 받는다 → [GAME_DESIGN.md §4](GAME_DESIGN.md). 예산이 남으면 유닛 +5 육성·칸 업그레이드·전술카드로 돌린다(무통화 — 골드·저축·레벨업 없음).
- 칸 위치는 초기 스폰 좌표와 접적 순서를 결정하며, **칸 업그레이드**로 그 칸이 영구적 의미를 갖는다 → [GAME_DESIGN.md §8](GAME_DESIGN.md), [BATTLE_DESIGN.md §8](BATTLE_DESIGN.md).

> **폐기:** 4×4 16칸 / 셀당 같은 종류 4명 누적 / 종류 단위 시너지 카운트 — 전부 누적 모델 전제였다.

## 5. 스킬·강화 부여 방식

- 유닛은 **고정 1스킬**을 가진다. 카드로 스킬을 추가 장착하지 않는다.
- 스킬 데이터·구조는 [SKILL_DESIGN.md](SKILL_DESIGN.md) 참조.
- **유닛 업그레이드 카드**는 상점에서 사서 필드 유닛에 **영구로** 붙는다 — 한 유닛당 **+5까지**, 부대와 함께 라운드를 넘어 유지된다.
- 영구 성장은 이 **+5 육성**과 **칸 업그레이드**로 일어나며, +5 상한이 개별 유닛의 폭주를 막는다 → [GAME_DESIGN.md §8](GAME_DESIGN.md).
