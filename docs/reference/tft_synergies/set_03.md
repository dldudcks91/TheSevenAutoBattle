## Mid-Set 변경 (Set 3.5: Return to the Stars)

> 출시: 2020-06 (LoL 10.12)
> Set 3.5는 14개 신규 챔피언 + 신규 트레잇 추가, 기존 일부 변경.

### 추가된 시너지
- **Astro (아스트로, 종족)** — 임계값 3: 모든 아군 마나 시작값 +30
- **Battlecast (전투기계, 종족)** — 임계값 2/4/6/8: 공격·피격 시 회복/광역 피해 누적
- **Mercenary (용병, 종족으로 재분류)** — 임계값 3: 승리 시 보너스 골드 베팅 시스템
- **Paragon (영웅, 직업)** — 임계값 1 (Lux): 스타 가디언 공격이 고정 피해 / 일반 효과 강화
- **Vanguard 잔존**, **Mystic 잔존**

### 제거된 시너지
- Demolitionist 제거
- Mech-Pilot 제거 (Set 3 전용)
- Mana-Reaver 제거 (이후 별도 형태로 재등장)

### 변경된 시너지
- **Celestial**: 데미지 기반 힐 → Omnivamp(전 피해 흡혈) 형태로 변경
- **Dark Star**: 고정 수치 → 비율 스케일링
- **Cybernetic**: 고정 수치 → 비율 기반 보너스
- **Infiltrator**: 공격속도 보너스 25/45/75%로 하향
- **Vanguard**: 방어력 수치 하향
- **Blaster**: 추가 탄환 수 1/2로 하향
