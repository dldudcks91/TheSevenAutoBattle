## 요약 (Set 8.0)
- 종족(Origin) 시너지: 12개
- 직업(Class) 시너지: 14개
- 합계: 26개 (대략)

## 종족 시너지 (Origins)

### A.D.M.I.N. (관리자)
- 임계값: 2 / 4 / 6
- 단계마다 "원인-결과" 프로그램을 선택, 조건이 충족되면 효과 발동(누적식)

### Anima Squad (애니마 스쿼드)
- 임계값: 2 / 4 / 6
- 처치 시 명성 누적, 명성에 비례해 체력·AD/AP 영구 증가

### Civilian (시민)
- 임계값: 1 / 2 / 3
- 시민 1명이 2초마다 마나 +2/+4/+10 회복

### Corrupted (타락: 피들스틱)
- 유니크 — 동료 사망/피격으로 영혼을 흡수해 AP 증가, 일정 시점에 각성

### Gadgeteen (개짓틴)
- 임계값: 3 / 5
- 라운드마다 무작위 강화 무기 1~2개 생성 (한 라운드 후 사라짐)

### Heart (심장)
- 임계값: 2 / 4 / 6
- 스킬 시전 시 팀 AP 누적

### LaserCorps (레이저 부대)
- 임계값: 3 / 6 / 9
- 전투 드론을 소환해 마법 피해, 단계 상승 시 드론·피해량 증가

### Mecha PRIME (메카 프라임)
- 임계값: 3 / 5
- 지정 PRIME에 강력한 AD/AP 보너스, 5단계는 모든 메카 강화

### Ox Force (옥스 포스)
- 임계값: 2 / 4 / 6
- 공속 누적, 단계가 오르면 체력 1로 떨어질 때 일시 무적

### Star Guardian (스타가디언)
- 임계값: 3 / 5 / 7 / 9
- 모든 마나 획득량 % 증가

### Supers (슈퍼)
- 임계값: 3
- 팀 전체 데미지 +20%, 3성 챔피언 1명당 +5%

### The Underground (지하세계)
- 임계값: 3 / 5
- PvP 승/패에 따라 금고 자물쇠 해제, 단계 후 보상 박스

### Threat (위협)
- 단일 — 시너지 없음. 대신 강력한 기본 스탯과 스킬 보유

## 직업 시너지 (Classes)

### Ace (에이스)
- 임계값: 1 / 4
- 일정 체력 이하 적 처형 (12% / 30%)

### Aegis (이지스)
- 임계값: 2 / 3 / 4 / 5
- 팀에 마저 부여, 이지스 본인은 추가 마저

### Arsenal (병기고: 아펠리오스)
- 유니크 — 전투 진입 시 무기 선택

### Brawler (난투꾼)
- 임계값: 2 / 4 / 6 / 8
- 최대 체력 비율 증가

### Defender (수비자)
- 임계값: 2 / 4 / 6
- 도발 + 팀에 방어력, 본인은 추가 방어력

### Duelist (검투사)
- 임계값: 2 / 4 / 6 / 8
- 기본 공격마다 공속 누적 (최대 10중첩)

### Forecaster (예보가: 잔나)
- 유니크 — 날씨에 따라 인접 아군에 다른 버프

### Hacker (해커)
- 임계값: 2 / 3 / 4
- 옴니뱀프 + H4ckerr!m 소환해 라이더를 후열로 침투

### Mascot (마스코트)
- 임계값: 2 / 4 / 6 / 8
- 팀 전체 주기적 회복, 사망한 마스코트가 회복량 증가

### Prankster (장난꾼)
- 임계값: 2 / 3
- 체력 절반에서 더미를 소환, 3단계는 적 기절

### Recon (정찰병)
- 임계값: 2 / 4 / 6
- 사거리 +2, 치명타 확률·스킬 치명타 부여

### Renegade (반항아)
- 임계값: 3 / 6
- 추가 데미지, 마지막 생존자가 더 큰 보너스

### Spellslinger (마법총잡이)
- 임계값: 2 / 4 / 6 / 8
- AP 증가, 5초마다 마법 오브 발사

### Sureshot (확실한 사수)
- 임계값: 2 / 3 / 4 / 5
- 4초마다 AD 영구 누적

## Mid-Set 변경 (Set 8.5 Glitched Out)

### 추가된 시너지
- **Parallel (패러렐)** — 종족 / 유니크. 두 이즈리얼이 함께면 스킬 강화
- **InfiniTeam (인피니팀)** — 종족 / 3·5·7. 보드에 포털 생성, 다른 차원 사본 소환
- **Riftwalker (리프트워커: 잭스)** — 종족 / 3. 잭이 차원을 열고 소환되어 인근 시너지 흡수
- **QuickDraw (퀵드로우)** — 직업 / 2·3·4. 두 발에 한 번씩 추가 발사체

### 제거된 시너지
- Arsenal, Recon, Civilian (Set 8.0 단발 시너지 정리)

### 변경된 시너지
- **Hacker** — 임계값 3/4/5로 변경 (옴니뱀프 수치 재조정)
- **Defender** — 도발/방어 수치 재조정
- **Star Guardian / Mecha PRIME / The Underground** — 메카닉 일부 리워크

## 요약 (Set 8.5)
- 종족 시너지: 15개 (4개 추가, 일부 제거)
- 직업 시너지: 13개 (3개 정리)
- 합계: 약 27~28개
