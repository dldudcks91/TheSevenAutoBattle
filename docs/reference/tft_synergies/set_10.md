# TFT Set 10: Remix Rumble (리믹스 럼블)

> 출시: 2023-12 (Set 10, 패치 13.24) — 미드셋 없이 단일 시즌
> 출처:
> - https://wiki.leagueoflegends.com/en-us/TFT:Remix_Rumble
> - https://lolchess.gg/tft/10.0
> - https://mobalytics.gg/blog/tft/tft-set-10-champions-traits/
>
> 컨셉: 룬테라의 음악 스킨 라인을 모티브 — 종족(Origin)은 음악 장르, 직업(Class)은 음악적 역할

## 요약
- 종족(Origin) 시너지: 16개 (음악 장르 기반)
- 직업(Class) 시너지: 12개
- 합계: 28개

## 종족 시너지 (Origins) — 음악 장르

### 8-Bit (8비트)
- 임계값: 2 / 4 / 6
- (2) +5% AD
- (4) +9% AD
- (6) +14% AD + 최종 하이스코어 보상

### Country (컨트리)
- 임계값: 3 / 5 / 7
- (3) Dreadsteed 동료 소환
- (5) 강화된 미드나잇 Dreadsteed
- (7) 강력한 인페르날 Dreadsteed

### Disco (디스코)
- 임계값: 3 / 4 / 5 / 6
- 단계별 공속·체력회복(% 최대체력) 증가, 5단계부터 디스코 볼 2개 소환

### EDM
- 임계값: 2 / 3 / 4 / 5
- EDM Drop의 효과·쿨 단축이 단계별로 강화 (90% → 135%)

### Emo (이모)
- 임계값: 2 / 4 / 6
- 받는 피해 감소 + 마나 보너스, 6단계는 +20 AP 추가

### HEARTSTEEL (하트스틸)
- 임계값: 3 / 5 / 7 / 10
- 라운드마다 하트(Heart) 적립, 단계가 높을수록 배율 증가, 10에서 매 라운드 보상 + 80% 보존

### Hyperpop (하이퍼팝)
- 임계값: 1 / 2 / 3 / 4
- 마나 + 공속 누적 (1단계 +5/+10% → 4단계 +20/+60%)

### ILLBEATS
- 유니크 — 별 등급별 영혼 촉수 2/2/8개 배치

### Jazz (재즈)
- 임계값: 2 / 3 / 4
- 체력·피해 % 증가 (단계마다 1.5%·1% → 4%·2%)

### K/DA
- 임계값: 3 / 5 / 7 / 10
- 최대체력·AD/AP 증가 (10단계는 매초 +10 마나 추가)

### Maestro (마에스트로)
- 유니크 — 고정 박자로 공격, 공속을 AD로 변환

### Mixmaster (믹스마스터)
- 유니크 — 모드 선택으로 기본공격/스킬 메커니즘 변경

### Pentakill (펜타킬)
- 임계값: 3 / 5 / 7 / 10
- 추가 데미지 % (15% → 99%), 10단계는 50% 피감 추가

### Punk (펑크)
- 임계값: 2 / 4 / 6
- 체력+AD 증가 (180/18% → 420/42%)

### True Damage (트루 대미지)
- 임계값: 2 / 4 / 6 / 9
- 추가 피해 % (15% → 99%), 9단계 블링 보너스 백금 등급

### Wildcard (와일드카드: 케인)
- 유니크 — 전투 결과에 따라 다크인/그림자 폼 변환, 처치마다 보상

## 직업 시너지 (Classes) — 음악 역할

### Big Shot (빅샷)
- 임계값: 2 / 4 / 6
- AD 증가, 스킬 시전 후 더 큰 보너스 (10/40% → 40/100%)

### Breakout (브레이크아웃: 아칼리)
- 유니크 — 팀 구성에 따라 K/DA 또는 True Damage 폼으로 변환

### Bruiser (싸움꾼)
- 임계값: 2 / 4 / 6
- 최대 체력 % 증가 (20% → 90%)

### Crowd Diver (크라우드 다이버)
- 임계값: 2 / 4 / 6
- 추가 피해 % (12% → 50%)

### Dazzler (현혹자)
- 임계값: 2 / 4 / 6
- 마법 피해 % 증가 (20% → 100%)

### Edgelord (엣지로드)
- 임계값: 3 / 5 / 7
- 공속 % (30% → 85%)

### Executioner (처형자)
- 임계값: 2 / 4 / 6
- 치명타 피해 + 저체력 적에게 치명타 확률 보너스

### Guardian (수호자)
- 임계값: 2 / 4 / 6
- 최대체력 비례 보호막 (25% → 70%)

### Mosher (모셔)
- 임계값: 2 / 4 / 6 / 8
- 공속 + 옴니뱀프 (20%/10% → 125%/30%)

### Rapidfire (래피드파이어)
- 임계값: 2 / 4 / 6
- 공속 % (4% → 16%) — 공격 시 누적

### Sentinel (파수꾼)
- 임계값: 2 / 4 / 6 / 8
- 방+마저 (16/16 → 100/100)

### Spellweaver (스펠위버)
- 임계값: 3 / 5 / 7 / 10
- AP + 시전마다 AP 누적 (20+1 → 130+6)

### Superfan (슈퍼팬)
- 임계값: 3 / 4 / 5
- 헤드라이너 강화 (완성 아이템 → 체력+옴니뱀프 → 광휘 아이템)

## Mid-Set 변경
- **Set 10에는 미드셋 업데이트가 없다.** 다음 시즌(Set 11 Inkborn Fables)으로 직접 전환.
- 대신 시즌 중 다수의 패치(13.24 ~ 14.5)에서 시너지·챔피언 밸런스 조정만 진행됨.
