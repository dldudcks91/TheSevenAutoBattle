## Mid-Set 변경 (Set 4.5: Festival of Beasts)

> 출시: 2021-01 (LoL 11.2)
> 6개 트레잇 제거 + 7개 신규 트레잇 추가, 챔피언 20명 신규 추가.

### 추가된 시너지
- **Daredevil (무법자, 종족)** — 임계값 1 (Samira): 매 2공격마다 대시·실드, 스타일 게이지
- **Dragonsoul (용혼, 종족)** — 임계값 3/6/9: 첫 피격 아군에 용의 축복(스탯 + 주기적 광역 마법 피해)
- **Fabled (신화, 종족)** — 임계값 3: 신화 챔피언 스킬 강화
- **Blacksmith (대장장이, 직업)** — 임계값 1 (Ornn): 매 라운드 후 별 등급 기반 아티팩트 제작
- **Executioner (처형자, 직업)** — 임계값 2/3/4: 체력 임계값 이하 적에게 치명타
- **Slayer (학살자, 직업)** — 임계값 3/6: 흡혈 + 잃은 체력 비율 추가 피해
- **Syphoner (흡수자, 직업)** — 임계값 2/4: 모든 피해의 일부 회복

### 제거된 시너지
- Dusk (황혼) 제거
- Tormented (고통) 제거 (Kayn 자체가 빠짐)
- Hunter (사냥꾼) 제거
- Shade (그림자) 제거
- Dazzler (현혹술사) 제거
- Moonlight (달빛) 제거 (실제로는 Set 4.5에서도 일부 남았다는 자료 있음 — 자료 부족)

### 변경된 시너지
- **Cultist**: 갈리오 소환 메커니즘 일부 조정
- **Mage**: 임계값 3/5/7로 변경 (기존 3/6/9)
- 다수 직업 임계값/수치 미세 조정
